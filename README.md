# SAEP Saúde

Sistema web desenvolvido para o projeto SAEP Saúde.

O sistema permite que usuários realizem login, visualizem atividades físicas, cadastrem novas atividades, filtrem atividades, utilizem paginação, curtam atividades e adicionem comentários.

---

# 1. Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- PostgreSQL
- Fetch API
- Git
- GitHub

---

# 2. Requisitos para instalação

Para executar o projeto é necessário possuir os seguintes programas instalados:

- Node.js
- npm
- PostgreSQL
- Git
- Navegador de internet

## 2.1 Node.js

O Node.js é utilizado para executar o servidor backend da aplicação.
